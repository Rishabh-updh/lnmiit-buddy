Generate your menu JSON

Open this when you need to create a menu file with Gemini.

Analyze the attached mess menu PDF and create a downloadable file named mess-menu.json containing ONLY valid JSON.

Use exactly this structure:
{
  "Sunday": {"Breakfast": [], "Lunch": [], "Snacks": [], "Dinner": []},
  "Monday": {"Breakfast": [], "Lunch": [], "Snacks": [], "Dinner": []},
  "Tuesday": {"Breakfast": [], "Lunch": [], "Snacks": [], "Dinner": []},
  "Wednesday": {"Breakfast": [], "Lunch": [], "Snacks": [], "Dinner": []},
  "Thursday": {"Breakfast": [], "Lunch": [], "Snacks": [], "Dinner": []},
  "Friday": {"Breakfast": [], "Lunch": [], "Snacks": [], "Dinner": []},
  "Saturday": {"Breakfast": [], "Lunch": [], "Snacks": [], "Dinner": []}
}

Put every food item as a separate string inside the correct meal array. Include all seven days and all four meals, using [] when a meal is missing. Do not include Markdown code fences, explanations, or any text outside the JSON object. Return the JSON as a downloadable .json file, not just as text.
